# Machine Photos

Place the 5 machine photos here, named according to this convention:

| File | Service |
|------|---------|
| `01-temperature-chamber.jpg` | Temperature Chamber |
| `02-temp-humidity-chamber.jpg` | Temperature & Humidity Chamber |
| `03-thermal-shock-chamber.jpg` | Thermal Shock Chamber |
| `04-rapid-temp-change.jpg` | Rapid Temperature Change |
| `05-vibration-tensile.jpg` | Vibration + Tensile/Compression |

## Photo Specifications

- **Aspect ratio:** 4:3 (preferred) or 16:10
- **Resolution:** Minimum 1200×900 px
- **Format:** JPG (compressed for web) or WebP
- **DPI:** 72 (web) — keep separate high-res versions (300 DPI) for print poster
- **Background:** Dark/lab settings preferred to blend with the dark theme
- **Treatment:** Will be automatically overlaid with 25% dark layer in the website

## Tips

- Shoot machines straight-on or at slight 3/4 angle
- Avoid bright/cluttered backgrounds
- Make sure the machine fills most of the frame
- If possible, include subtle lighting that highlights technical surfaces
